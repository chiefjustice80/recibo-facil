Datenschutzerklärung für Organiza

Stand: 10. Juni 2026

1. Verantwortlicher

Verantwortlich für diese App ist:

Facil Labs
E-Mail: facil.labs@gmail.com

Diese Datenschutzerklärung beschreibt, wie die App Organiza mit Daten umgeht.

2. Grundsatz

Organiza ist als lokale App konzipiert. Die Hauptfunktionen der App können ohne Benutzerkonto, ohne Anmeldung und ohne Cloud-Synchronisierung genutzt werden.

Die in der App eingegebenen Daten werden grundsätzlich lokal auf dem Gerät des Nutzers gespeichert.

3. Welche Daten verarbeitet die App lokal?

Nutzer können in der App freiwillig Informationen speichern, zum Beispiel:

  • Produktnamen
  • Barcodes
  • Marken
  • Mengenangaben
  • Lagerorte
  • Mindesthaltbarkeits- oder Ablaufdaten
  • Erinnerungseinstellungen
  • Beleginformationen wie Titel, Händler, Kaufdatum, Betrag, Kategorie, Garantieinformationen und Notizen
  • Fotos von Belegen oder Kaufnachweisen

Diese Daten werden lokal auf dem Gerät gespeichert und nicht an eigene Server von Facil Labs übertragen.

4. Kamera und Fotos

Die App kann Zugriff auf die Kamera und auf vom Nutzer ausgewählte Bilder anfordern.

Diese Berechtigungen werden verwendet, damit Nutzer:

  • Barcodes scannen können
  • Belege oder Kaufnachweise fotografieren können
  • bereits vorhandene Belegbilder aus der Galerie auswählen können

Die ausgewählten oder aufgenommenen Bilder werden lokal in der App gespeichert. Eine Übertragung an eigene Server erfolgt nicht.

5. Benachrichtigungen

Die App kann lokale Benachrichtigungen verwenden, um Nutzer an Ablaufdaten, Mindesthaltbarkeitsdaten oder Garantieinformationen zu erinnern.

Diese Erinnerungen werden lokal auf dem Gerät geplant. Es erfolgt keine Übertragung dieser Erinnerungsdaten an eigene Server.

6. Barcode- und Produktinformationen

Die App kann optional Produktinformationen anhand eines Barcodes nachschlagen.

Wenn diese Funktion genutzt wird, kann der eingegebene oder gescannte Barcode an einen externen Produktdaten-Dienst, zum Beispiel Open Food Facts, übermittelt werden, um passende Produktinformationen abzurufen.

Dabei handelt es sich um eine Produktnummer. Facil Labs verwendet diese Funktion nicht, um Nutzer persönlich zu identifizieren.

7. Keine Benutzerkonten

Für die Nutzung der App ist kein Benutzerkonto erforderlich.

Organiza erhebt keine Namen, E-Mail-Adressen, Passwörter oder sonstige Kontodaten zur Anmeldung.

8. Keine Weitergabe an Dritte

Facil Labs verkauft keine Nutzerdaten und gibt keine lokal gespeicherten App-Daten an Dritte weiter.

Eine Weitergabe kann nur erfolgen, wenn Nutzer selbst Inhalte außerhalb der App teilen oder wenn dies gesetzlich erforderlich wäre.

9. Speicherung und Löschung

Die vom Nutzer eingegebenen Daten bleiben lokal auf dem Gerät gespeichert, bis sie vom Nutzer in der App gelöscht werden oder die App deinstalliert wird.

Beim Löschen von Einträgen versucht die App, zugehörige lokale Daten wie gespeicherte Belegbilder oder Erinnerungen ebenfalls zu entfernen.

10. Datensicherheit

Da die Hauptdaten lokal auf dem Gerät gespeichert werden, hängt der Schutz dieser Daten auch von den Sicherheitseinstellungen des Geräts ab.

Nutzer sollten ihr Gerät durch geeignete Maßnahmen wie Gerätesperre, PIN, Passwort oder biometrische Entsperrung schützen.

11. Kinder und Jugendliche

Organiza richtet sich nicht speziell an Kinder.

Die App enthält keine Inhalte, die gezielt für Kinder erstellt wurden.

12. Änderungen dieser Datenschutzerklärung

Diese Datenschutzerklärung kann angepasst werden, wenn sich Funktionen der App oder rechtliche Anforderungen ändern.

Die jeweils aktuelle Version wird über diese Seite bereitgestellt.

13. Kontakt

E-Mail: facil.labs@gmail.com

Política de Privacidade do Organiza

Atualizado em: 10 de junho de 2026

1. Responsável

O responsável por este aplicativo é:

Facil Labs
E-mail: facil.labs@gmail.com

Esta Política de Privacidade descreve como o aplicativo Organiza trata dados.

2. Princípio geral

O Organiza foi desenvolvido como um aplicativo local. As principais funções podem ser usadas sem conta de usuário, sem login e sem sincronização em nuvem.

Os dados inseridos no aplicativo são armazenados principalmente de forma local no dispositivo do usuário.

3. Quais dados o aplicativo processa localmente?

O usuário pode salvar voluntariamente informações no aplicativo, por exemplo:

  • nomes de produtos
  • códigos de barras
  • marcas
  • quantidades
  • locais de armazenamento
  • datas de validade ou vencimento
  • configurações de lembretes
  • informações de recibos, como título, loja, data da compra, valor, categoria, garantia e observações
  • fotos de recibos ou comprovantes de compra

Esses dados são armazenados localmente no dispositivo e não são enviados para servidores próprios da Facil Labs.

4. Câmera e fotos

O aplicativo pode solicitar acesso à câmera e a imagens selecionadas pelo usuário.

Essas permissões são usadas para permitir que o usuário:

  • escaneie códigos de barras
  • fotografe recibos ou comprovantes de compra
  • selecione imagens existentes da galeria

As imagens selecionadas ou capturadas são armazenadas localmente no aplicativo. Elas não são enviadas para servidores próprios.

5. Notificações

O aplicativo pode usar notificações locais para lembrar o usuário sobre datas de validade, vencimento ou informações de garantia.

Esses lembretes são programados localmente no dispositivo. Os dados dos lembretes não são enviados para servidores próprios.

6. Código de barras e informações de produtos

O aplicativo pode opcionalmente buscar informações de produtos com base em um código de barras.

Quando essa função é usada, o código de barras inserido ou escaneado pode ser enviado a um serviço externo de informações de produtos, por exemplo Open Food Facts, para obter informações correspondentes.

O código de barras é uma identificação do produto. A Facil Labs não utiliza essa função para identificar pessoalmente o usuário.

7. Sem contas de usuário

Não é necessário criar uma conta para usar o aplicativo.

O Organiza não coleta nomes, endereços de e-mail, senhas ou outros dados de login.

8. Sem venda ou compartilhamento de dados

A Facil Labs não vende dados de usuários e não compartilha dados armazenados localmente no aplicativo com terceiros.

O compartilhamento só pode ocorrer se o próprio usuário compartilhar conteúdos fora do aplicativo ou se isso for exigido por lei.

9. Armazenamento e exclusão

Os dados inseridos pelo usuário permanecem armazenados localmente no dispositivo até que sejam excluídos pelo usuário no aplicativo ou até que o aplicativo seja desinstalado.

Ao excluir registros, o aplicativo tenta remover também os dados locais relacionados, como imagens de recibos ou lembretes salvos.

10. Segurança dos dados

Como os principais dados são armazenados localmente no dispositivo, a proteção desses dados também depende das configurações de segurança do aparelho.

Recomendamos que o usuário proteja seu dispositivo com bloqueio de tela, PIN, senha ou desbloqueio biométrico.

11. Crianças e adolescentes

O Organiza não é direcionado especificamente a crianças.

O aplicativo não contém conteúdos criados especificamente para crianças.

12. Alterações nesta Política de Privacidade

Esta Política de Privacidade pode ser atualizada caso as funções do aplicativo ou os requisitos legais mudem.

A versão atual estará disponível nesta página.
